# Support

Support is community-based and best effort. There is no response-time SLA or managed SSH service.

1. Check [getting started](docs/getting-started.md), [troubleshooting](docs/troubleshooting.md) and [compatibility](docs/compatibility.md).
2. Search [existing issues](https://github.com/stark-ai-de/ssh-manager/issues).
3. Open a [support question](https://github.com/stark-ai-de/ssh-manager/issues/new?template=question.yml), [bug report](https://github.com/stark-ai-de/ssh-manager/issues/new?template=bug_report.yml), or [feature request](https://github.com/stark-ai-de/ssh-manager/issues/new?template=feature_request.yml).

Include your package version or source commit, Node/pnpm versions, OS, access path (library/API/CLI/viewer/MCP), expected behavior and a synthetic reproduction. State whether a check was passed, failed, skipped or not run.

Do not attach state directories, real host inventories, credentials, vault backups, tokens or unredacted terminal recordings. Replace identifying values consistently so the reproduction remains understandable. Security concerns go to the [private reporting channel](SECURITY.md); conduct concerns follow the [code of conduct](CODE_OF_CONDUCT.md).
